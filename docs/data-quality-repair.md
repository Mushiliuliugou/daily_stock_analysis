# 行情与报告修复

- 港股先查询东方财富单股票接口，读取量比与换手率，保留全市场接口和新浪备用路径。请求失败重试一次，并记录报价时间。
- 使用成交额与当日高低价核对日线成交量单位，确认以手为单位时统一为股。已按股返回的数据保持原值。
- 缺失或无效的量比、换手率统一显示 N/A，百分号仅用于有效换手率数值。
- 市场统计获取失败时从模型输入中移除全零统计，并明确市场统计不可用。
- 修正港股新浪备用报价来源。

## 安装

更新包包含四个源文件和两份项目文档。解压后按原路径覆盖仓库同名文件。GitHub 网页上传应分别进入 data_provider、src、docs 目录上传对应文件。保留原有 Secrets。
保存到 main 后手动运行一次 full，下载新报告和日志核验。

## 验证

379 项项目测试通过，包括日线成交量校验、港股补齐与降级、市场复盘和通知。四个修改源文件语法检查通过。
公开单股票接口通过 curl 真实返回了理想汽车价格、量比、换手率和行情时间。Python requests 的实际联网调用在本机连接中断，尚未完成 GitHub Actions 环境在线验证。并非已经部署或验证过完整邮件流程。

## 验收

新日志应出现 [HK single quote]，并打印 volume_ratio、turnover_rate、timestamp。若请求失败，日志会记录重试后进入原备用流程。
万科历史成交量归一后，同单位的相邻交易日比较不再发生手/股混算。
大盘统计失败时不得把缺失统计传成真实零值。

## 回滚

用安装前保存的四个源文件和两份文档覆盖本次文件。

有效港股单标的报价即使缺少可选量比/换手率也保留，避免降级丢失行情时间和价格区间。实时开盘价、最高价、最低价缺失时保持缺失，不用最新价或昨收制造零振幅。

线上验收发现上游新增的300秒单股限制会在公共数据源连续超时后丢弃万科结果。每日工作流的未配置默认值改为600秒（保留自定义覆盖），并核验成功/失败汇总；任一个股失败时运行显示失败，报告和日志仍通过 always() 上传。
